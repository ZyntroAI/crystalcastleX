🔴 Redis Reliability Layer

🧠

Cache

Stores short-lived diagnostic responses and reduces repeated provider/API calls.

🛡

Circuit Breaker

Opens a provider circuit after repeated failures.

🔄

Recovery

Automatically transitions OPEN → HALF_OPEN → CLOSED. 

                    Request
                       │
                       ▼
                 Circuit Breaker
                       │
             ┌─────────┴─────────┐
             │                   │
          CLOSED                OPEN
             │                   │
             ▼                   ▼
          Provider          Fallback Model
             │
        ┌────┴────┐
        │         │
     Success   Failure
        │         │
        ▼         ▼
     CLOSED    failures++
                    │
                    ▼
              threshold reached
                    │
                    ▼
                  OPEN
