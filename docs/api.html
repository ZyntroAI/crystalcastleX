Crystal Castle API

Version 1.0.0

API for image-to-video generation, asynchronous pipeline processing, affiliate link monitoring, service health, and alerts.

Authentication Generation Monitoring Alerts Schemas Errors

Authentication

Protected endpoints require an API key in the X-API-KEY request header. 

X-API-KEY: YOUR_API_KEY
Never commit API keys to source control or expose them in client-side JavaScript.

Generation

POST /v1/generate

Starts an asynchronous image-to-video generation job.

Authentication required.

Headers

Name Required Description
X-API-KEY Yes API authentication key.
Idempotency-Key No Prevents duplicate jobs when a request is retried.

Request

{
  "product_id": "product-123",
  "image_url": "https://example.com/product.jpg",
  "platform": "tiktok",
  "style": "streetwear-retro",
  "metadata": {
    "campaign": "summer-2026"
  }
}

Response

202 Job accepted. 

{
  "job_id": "job_01JXYZ123",
  "status": "queued",
  "created_at": "2026-08-23T04:00:00Z"
}

Error responses

Status Description
400 Invalid request.
401 Authentication failed.
429 Rate limit exceeded.
503 Generation service unavailable.

GET /v1/generate/{job_id}

Returns the current state of a generation job.

Authentication required.

Path parameters

Name Required Description
job_id Yes Unique generation job identifier.

Response

200 Generation status. 

{
  "job_id": "job_01JXYZ123",
  "status": "completed",
  "artifact_url": "https://cdn.example.com/video.mp4",
  "created_at": "2026-08-23T04:00:00Z"
}

Errors

401 Authentication failed.
404 Generation job not found.

Monitoring

GET /v1/status

Returns service health and pipeline metrics.

Authentication is not required for this endpoint. 

{
  "uptime": 86400,
  "version": "1.0.0",
  "queue_length": 3,
  "healthy": true
}

POST /v1/monitor/link

Validates or monitors an affiliate URL.

Authentication required.

Request

{
  "affiliate_url": "https://example.com/product/123",
  "check_now": true
}

Response

{
  "ok": true,
  "reason": "Link is reachable",
  "expires_at": "2026-12-31T23:59:59Z"
}

Errors

400 Invalid affiliate URL.
401 Authentication failed.
429 Rate limit exceeded.

Alerts

POST /v1/alerts

Sends a manual alert through configured notification providers, such as LINE or a webhook.

Authentication required.

Request

{
  "level": "warning",
  "message": "Generation queue is growing",
  "meta": {
    "queue_length": 100
  }
}

Response

202 Alert accepted.

Errors

400 Invalid alert request.
401 Authentication failed.
429 Rate limit exceeded.

Data Schemas

GenerationRequest

Field Type Required Description
product_id string Yes Product identifier.
image_url URI Yes Source product image.
platform enum No tiktok, shopee, reels, or threads.
style string No Generation profile or prompt name.
metadata object No Additional application metadata.

GenerationStatus

Status Description
queued Job is waiting in the processing queue.
processing Job is currently being processed.
completed Generation completed successfully.
failed Generation failed.
cancelled Generation was cancelled.

AlertRequest

Field Type Required
level info | warning | critical Yes
message string Yes
meta object No

Error Handling

API errors use a consistent error response structure. 

{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "Invalid image URL.",
    "request_id": "req_01JXYZ123"
  }
}
Status Meaning
400 Invalid request.
401 Authentication failed.
404 Resource not found.
429 Rate limit exceeded.
503 Service unavailable.
